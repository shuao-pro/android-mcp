Connection Setup Wizard

Follow these steps to connect your Android device.

1
Install ADB
Download Android SDK Platform Tools and add to PATH.
—
2
Connect Device
Connect phone via USB with USB Debugging enabled, or use wireless ADB.
—
3
Start Android MCP Service
Start Shizuku → open Android MCP app → grant Shizuku permission → tap Start. The app listens on port 18080 for device control commands.
—
4
MCP Server & API Frontend
The MCP server (SSE + Streamable HTTP) runs on port 9000. Connect Kai 9000 (F-Droid) or any MCP client to the endpoints below, then chat to control the device.
—
5
Configure Environment
Create .env file in the project root (copy from .env.example). Default config works out of the box.
—
6
AI Vision API Optional
Set VISION_PROVIDER and VISION_API_KEY in .env to enable AI chat and screen element recognition.
